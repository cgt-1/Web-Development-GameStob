# Web-Development-GameStob
A responsive game retail website designed in Figma and developed using HTML, CSS, and JavaScript. GameStoB is a fictional game retailer featuring digital and physical games, DLCs, and store locations.

✨ Features
- Responsive web design
- Game catalog and product details
- Purchase form with JavaScript validation
- Company information and store locations
- Custom UI/UX design and Figma prototype

🛠️ Built With
* Figma — UI/UX design and prototyping
* HTML5 — Website structure
* CSS3 — Styling and responsive layouts
*JavaScript — Interactivity and form validation

📁 Folder Structure
Web Development GameStob/
├── figma/          # Figma design files
├── vscode/         # VS Code project configuration
├── assets/         # Images and other assets
├── css/            # Stylesheets
├── html/           # HTML pages
└── js/             # JavaScript files

🚀 Getting Started
Clone this repository.
Open the project folder.
Open the main HTML file in your browser.

No additional installation is required.

GameStoB is a fictional brand created for a web development project.
